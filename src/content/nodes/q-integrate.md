An agent weighing its tools, a brain combining senses, a committee reaching a verdict. Each faces the same structure: several partial views, one output.

Two questions usually get blurred together here. The first is whether the integration behavior is stable and describable. The second is whether that behavior tracks reality. The first needs no ground truth at all. The second does, and it should only enter once the first is settled.
